# Zamówienia

GitHub Pages nie ma backendu, więc nie zapisujemy danych klientów w tym publicznym folderze.

Po podpięciu backendu lub formularza serwerowego endpoint zamówień powinien zapisywać rekordy tutaj po stronie serwera, poza publicznym repozytorium.

W wersji demonstracyjnej zamówienia są tymczasowo zapisywane w `localStorage` przeglądarki pod kluczem `kreslOrders`.
